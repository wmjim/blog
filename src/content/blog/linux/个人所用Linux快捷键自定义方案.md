## 快捷键哲学

| 修饰键  | 主要功能定位                           | 设计考量                 |
| ------- | -------------------------------------- | ------------------------ |
| `Super` | 系统级操作（窗口、工作区、启动器）     | 可作为系统的元键盘，避免 |
| `Alt`   | 应用内操作（菜单、切换、上下文菜单）   |                          |
| `Shift` | 扩展功能和反向操作                     |                          |
| `Ctrl`  | 文本编辑与命令（复制、粘贴、终端控制） | 遵守跨平台标准           |
| `Tab`   | 切换与补全                             |                          |
| `Esc`   | 取消和退出                             |                          |
